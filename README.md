## Outras atividades

- Na [AtividadeFatura](AtividadeFatura/), desenvolvi a classe `Fatura` e exemplos. Para executá-los, seleciono `Principal` ou `Teste2Principal`.
- Na [AtividadeElevador](AtividadeElevador/), organizei as classes `Elevador` e `Principal`. Para executar, seleciono `Principal`.
- No [desafioKata](desafioKata/), trabalhei no desafio do cofre. Para executá-lo, seleciono `Main`.

## Como abro no IntelliJ IDEA

Para consultar os exercícios, abro a pasta raiz deste repositório no IntelliJ IDEA. Configurei os módulos para que cada um use sua própria pasta `src`. Se o IntelliJ solicitar um JDK, seleciono o JDK 26.

Quando uma atividade tem uma classe `main`, seleciono a classe indicada acima para executá-la. As outras classes são modelos e não iniciam um programa sozinhas.
